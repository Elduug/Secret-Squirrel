# Contributing to Secret Squirrel

Thank you for helping improve Secret Squirrel.

## Before opening an issue

- Search existing issues first.
- Never attach real employee names, usernames, temporary passwords, exported CSV files, or internal identity-system details.
- Use GitHub's private security reporting flow for vulnerabilities.

## Development workflow

1. Fork the repository and create a focused branch.
2. Preserve the offline-only design; network access is out of scope.
3. Keep the interface explicit that generated values are temporary onboarding credentials.
4. Run `./build.sh` and verify the resulting app locally.
5. Open a pull request explaining the change and verification performed.

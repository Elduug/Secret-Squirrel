# Security policy

## Scope

Secret Squirrel is a local onboarding convenience tool, not a password manager, secrets manager, or general-purpose security product. Generated credentials must be temporary, expire quickly, be replaced at first sign-in, and be protected by rate limiting and lockout controls in the destination identity system.

Do not use it for personal, administrator, service, production, recovery, encryption, or long-lived credentials.

## Reporting a vulnerability

Please do not disclose vulnerabilities or real credentials in a public issue. Use [GitHub private vulnerability reporting](https://github.com/Elduug/secret-squirrel/security/advisories/new). If that feature is unavailable, contact [@Elduug](https://github.com/Elduug) through GitHub without including sensitive evidence in the first message.

Include the affected version, macOS version, reproduction steps, and impact. You should receive an acknowledgment within seven days.
